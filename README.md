# Active Recall Flashcard Reviewer
## This is a simple Python project that helps you review by providing your flashcards and letting you answer them to make you learn your topic more easily.

## Features:
- Provide flash cards
- Answering flash cards
- Show correct answer
- Show scores
- Create multiple decks

## How to run the program:
- Have Python installed
- Download the file "activerecallfr.py"
- Open a terminal or command prompt.
- Run the program by clicking "run"
- Follow the instructions on the screen to make decks and study them.

## Example output:
- Make a new deck: yes
- Add a question: yes

- Q: What's the capital of France?

- Play Deck?: yes

- Wrong Answer!
